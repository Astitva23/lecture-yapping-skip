## Skipping unimportant (yapping) parts during lectures to save time
-----
This script allows the user to look at a community highlighed part of a lecture on the website, which you can skip to save yourself some time.

# How it works  

- Once the user has the script activated, they can just press Y or click on the UI in the top left to highlight the region where they think that the teacher is not teaching (story, motivation, crashout etc.)

- Then press Y again to end the selection. now it will appear as a yellow region in your player seek bar.

- If more than 3 people find the same region to be marked as potential non teaching talk, then it will appear as a red region on the seek bar.

- All data is anonymously stored in db.

# How to install 

- Install tamper monkey from google webstore

- Download the script, copy paste its contents or upload it to your tamper monkey extension in google chrome.

- Done, then just use it whenever needed.

# FAQs 

1. "I don't see anything when i open a lecture"

As this project is entirely community led, so it may mean that people have not yet marked the lecture that you are watching.

2. "Why are my contributions not being shown to other people"

The contributions work on a ratio and percentage basis, if more than 3 people match the region where you contributed, only then will it be shown globally.
